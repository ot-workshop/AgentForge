Implementation side of the AgentForge P0 pilot, written against
`agentforge-v2.4.md` (§2.1–§2.5, §3.1, appendix A) in `#流水线`.

Status: **draft, not pushed**. This tree is the working copy of @员工三号.

## What is here

- `bin/forge.js` — CLI: `run`, `replay`, `incremental`, `verify-chain`, `snapshot`, `serve`.
- `src/project.js` — the single projection function (full replay and SSE both call it).
- `src/eventlog.js` — events.jsonl reader/verifier/writer (hash chain, half-line rule).
- `src/lock.js` — exclusive run writer guard (`E_EVENTS_LOCKED`).
- `src/run.js` — linear orchestrator (design → build → verify) + fake runner contract.
- `src/serve.js` — Live: `/healthz`, `/snapshot`, `/events?since=N` (SSE), plus the M2-A canvas routes below.
- `test/` — A1, A2.1/A2.2/A2.4, A4.1/A4.3, A5.2/A5.4/A5.5/A5.8/A5.9/A5.11/A5.12.

## Canvas prototype (M2-A)

`node bin/forge.js serve`, then open `http://127.0.0.1:8787/ui` (the static
page can also be opened directly from `ui/`, but then only export works).
Drag a block from the library onto the canvas, drag a node's right port onto
another node's left port to connect, click a node or edge to edit it, then
"导出 YAML". Errors point back at the canvas node by id.

Routes added by `src/serve.js` (existing routes unchanged):

- `GET /ui` — the page (also `/ui/canvas.js`, `/flow-yaml.js`, `/blocks.json`, `/samples.json`).
- `GET /blocks` — the block library, scanned from `blocks/*/v*.yaml`; a broken
  block file is reported in `warnings` (the rest still list).
- `GET /samples` — `flows/*.yaml` with their text.
- `POST /validate` — body `{"flow": "<YAML text>", "path": "<optional>"}`; runs
  the same `validateP0`/`validateFlow` as `forge validate` against this
  server's root and answers 200 with `{"errors":[...]}` (same JSON as the CLI;
  `path` defaults to `ui-export.yaml`). Not POST → 405; body over 1 MiB
  (`1024 * 1024` bytes) → 413 `E_INVALID_ARGS` with `fix.detail = "payload too large"`;
  `path` that is absolute, has `..`, NUL or line breaks → 400. Nothing is
  written outside `os.tmpdir()`.

Known limit: the CLI `forge validate` looks for `blocks/` next to the flow
file, while `/validate` uses this server's root. The two produce identical JSON
for a flow inside the project; for a flow outside it they can disagree until
`validate` and `run` share one root (entry-consistency PR).

`ui/samples.json` and `ui/blocks.json` are generated by
`node tools/canvas-sync.mjs`; `test/canvas.test.js` fails if they drift.
